# 🏏 Cricket Champions

A fast, browser-based cricket batting challenge. Read the delivery, time your shot, and put runs on the board!

## Play

Open **[Cricket Champions](https://parthmodh101-creator.github.io/Cricket-Champions/)** after enabling GitHub Pages, or run it locally:

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Choose a shot when the ball reaches the batter. You can also press **Space** to play a drive.

## Game features

- A responsive cricket ground and animated deliveries
- Four batting choices: defend, drive, loft, and sweep
- Timing-based outcomes, boundaries, wickets, and running
- A 2-over challenge with five wickets
- Live scoreboard, run rate, remaining balls, and recent deliveries
- Optional sound effects generated in the browser
- No frameworks, packages, or external assets required

## Controls

| Control | Action |
| --- | --- |
| Defend | Safer shot, usually a dot or single |
| Drive | Balanced attacking shot |
| Loft | High-risk attempt at a six |
| Sweep | Placement-focused leg-side shot |
| Spacebar | Play a drive |

## Run locally

No build step is needed. Simply open `index.html` in your browser.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. After GitHub finishes publishing, your game will be available at the Pages link above.

## Built with

HTML, CSS, and vanilla JavaScript.
